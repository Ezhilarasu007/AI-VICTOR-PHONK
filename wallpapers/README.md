# AI VICTOR PHONK - Wallpapers

This folder contains custom wallpapers for the AI VICTOR PHONK application.

## Wallpaper Themes

1. **Brazilian Phonk** - Warm orange and purple gradients
2. **Drift Phonk** - Dark and neon blue
3. **Dark Phonk** - Deep purple and black
4. **Atmospheric Phonk** - Soft cyan and purple
5. **Aggressive Phonk** - Red and dark contrast

## Usage

Users can upload their own wallpapers through the Settings section, or you can add default wallpapers here.

To add a new wallpaper:
1. Add your image file to this folder
2. Update the application to include it in the wallpaper selector
